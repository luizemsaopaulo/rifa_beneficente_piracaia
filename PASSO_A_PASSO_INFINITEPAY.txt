DEPLOY CORRIGIDO - IMPORTANTE
=============================
Use DEPLOY_INFINITEPAY.bat.

Agora ele abre uma segunda janela CMD que fica aberta mesmo em caso de erro.
O processo verifica:
- Node.js instalado
- Node.js 20 ou superior
- npx
- Supabase CLI
- login do Supabase
- deploy com modo DEBUG

Todo o resultado fica salvo em:
deploy_infinitepay_log.txt

Se der erro, envie esse TXT ao ChatGPT.

1) Execute supabase\INSTALAR_SUPABASE.sql no SQL Editor.
2) Execute DEPLOY_INFINITEPAY.bat para publicar o webhook/gateway.
3) Execute ABRIR_RIFA.bat.
4) Escolha 3 numeros: o total deve mostrar R$ 30,00.
5) Clique em pagar: deve abrir o checkout da InfinitePay.
6) Apos pagamento aprovado, os numeros mudam para Pago automaticamente.
