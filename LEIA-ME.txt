RIFA BENEFICENTE PIRACAIA - VERSAO COMPLETA INFINITEPAY
==========================================================

VALOR: R$ 10,00 por numero
NUMEROS: 001 a 200
PREMIO: R$ 200 via Pix
SORTEIO: 18/10/2026 as 20h
LIVE: Instagram @TUDO.DEHELENA

PAGAMENTO
- Somente InfinitePay no site.
- InfiniteTag configurada: luizwl
- O valor e calculado automaticamente: quantidade x R$ 10,00.
- Exemplo: 3 numeros = R$ 30,00.
- O site NAO exibe Pix pessoal.
- A InfinitePay gera um checkout diferente para cada pedido.
- O webhook valida o pagamento na InfinitePay antes de marcar como Pago.

FLUXO
1. Pessoa escolhe os numeros.
2. Informa nome e WhatsApp.
3. O Supabase pedido os numeros e cria um order_nsu exclusivo.
4. A Edge Function cria o checkout da InfinitePay com o valor correto.
5. A pessoa paga no checkout.
6. O webhook consulta payment_check na InfinitePay.
7. Se o valor e o pagamento forem validos, os numeros mudam automaticamente para Pago.
8. Apenas numeros pagos entram no sorteio oficial.

PRIMEIRA INSTALACAO / ATUALIZACAO
1. No Supabase > SQL Editor, execute TODO o arquivo:
   supabase/INSTALAR_SUPABASE.sql
   Pode executar novamente mesmo se voce rodou a versao anterior.

2. Publique a Edge Function da InfinitePay.
   Opcao facil no Windows: execute DEPLOY_INFINITEPAY.bat.
   Se pedir login, execute no Prompt:
      npx supabase login
   e depois execute DEPLOY_INFINITEPAY.bat novamente.

   Comando equivalente:
      npx supabase functions deploy infinitepay-gateway --project-ref qzpezwscmwfznzzbrxpb --no-verify-jwt

3. Abra ABRIR_RIFA.bat para testar localmente.
4. Abra ABRIR_ADMIN.bat para o painel.

ALTERACAO - SEM RESERVA MANUAL
==============================
O cliente nao pode guardar numero sem pagar.
Fluxo publico: Disponivel -> Em pagamento -> Pago.

"Em pagamento" e apenas uma trava tecnica criada quando o cliente clica em COMPRAR e o checkout InfinitePay e aberto.
Se a InfinitePay falhar ao criar o checkout, os numeros sao liberados imediatamente.
No painel admin e possivel liberar manualmente um pedido abandonado.

IMPORTANTE PARA QUEM JA INSTALOU A VERSAO ANTERIOR:
1. Execute novamente supabase/INSTALAR_SUPABASE.sql no SQL Editor.
2. No Dashboard > Edge Functions > infinitepay-gateway > Code, substitua o codigo pelo novo index.ts deste projeto e faca Deploy.
3. Mantenha Verify JWT with legacy secret DESLIGADO.
